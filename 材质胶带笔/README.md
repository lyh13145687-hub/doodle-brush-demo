# 纹理胶带笔资源规则

纹理胶带笔沿用锯齿胶带笔的笔头遮罩、连续笔身、首尾笔头和轨迹平滑逻辑，但素材不再打成一个绑定包。

## 可替换素材

两类图片素材分别上传、分别保存版本、分别替换：

1. **笔刷纹理**：PNG/JPG 图片，在底色上以正片叠底方式平铺。
2. **图案**：PNG/JPG 图片，在纹理上独立平铺；白底图案可直接使用正片叠底，透明底图片也兼容。

任何一类图片素材更新时，都不要求重新上传另一类。颜色不单独上传配置文件，直接使用编辑器色条选择。

“替换素材”中会展示目录里的全部内置纹理和图案，也可以通过“＋”上传自定义图片。

## 自动四方连续

纹理和图案分别拥有独立开关。开启后，素材先被等比缩放到安全尺寸，再生成横向镜像、纵向镜像和横纵镜像组成的 2×2 单元。这个单元重复平铺时，左右边与上下边都能自然衔接。关闭时直接平铺原图。

## 自动图案色彩

关闭时，图案保留 PNG 原色并以普通“正常”模式覆盖在底色和纹理之上；只有纹理使用正片叠底。开启时，先用图片四角估算背景色，提取与背景有色差的部分作为图案遮罩，再根据胶带底色生成图案色：

- 底色很暗：图案使用白色，保证可读性。
- 底色很浅：保持同色相，生成高饱和度、较深的图案色。
- 底色高饱和：保持同色相，生成低对比的浅色图案。
- 其他中间色：保持同色相，根据底色明暗选择深色或浅色图案。

因此浅蓝底会得到高饱和度蓝色图案，黑底会得到白色图案，高饱和粉色底会得到浅粉色图案。

## 默认行为

- 纹理胶带笔首次切换时，透明度为 80%。
- 纹理胶带笔首次切换时，默认颜色为 `#c1dce6`；两种胶带笔分别记忆各自选中的颜色。
- 默认笔头为“笔头1圆弧锯齿”，可继续切换笔头目录中的其他笔头。
- 已完成的笔画保留绘制时的资源快照；替换资源只影响之后的新笔画，避免撤销/重做时外观变化。
